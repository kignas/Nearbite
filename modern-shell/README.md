# Eatswada modern shell — Stage 1

Isolated React + TypeScript + Vite shell for the planned Home/Orders migration.

- Separate from the current production HTML pages.
- No existing page, API flow, URL, or bottom navigation is changed in Stage 1.
- Run `npm install`, `npm run build`, and `npm run dev` from this directory.
- Do not deploy or route users to this shell until migration and regression tests are complete.
